Um projeto estilo ERP sobre controle de finanças pessoais, com gráficos, notificações, emails, login, recuperação de senha...

# Tecnologias que quero usar
1. Java + Spring Boot
2. NextJS ou Angular + ShadCN + TailwindCSS
3. Docker
4. AWS (algum free tier, lambda)
5. Microserviço com algum processamento async que dê pra usar aws lambdas

# Qual o objetivo do projeto
Quero criar um projeto que englobe a maior parte de áreas e assuntos possíveis que são lacunas do meu conhecimento
1. System Design
2. Arquitetura de Software
3. Segurança
4. DevOps - CI/CD 
5. Infra / Infra as Code com Terraform
6. Rede / Proxy com Nginx
7. Mensageria com Kakfa ou rabbitMQ
8. Cloud com AWS
9. Testes unitários e integração
10. Observabilidade
11. Microserviços
12. Kubernets
